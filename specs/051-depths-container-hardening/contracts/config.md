# Config additions (051)

| Flag / env | Default | Meaning |
|---|---|---|
| `--shell-policy` / `DEPTHS_SHELL_POLICY` | `strict` | `strict` or `relaxed` (data-model table) |
| `--compose-policy` / `DEPTHS_COMPOSE_POLICY` | `warn` | `warn` or `enforce` |

Invalid values refuse to start with a message naming the variable.
