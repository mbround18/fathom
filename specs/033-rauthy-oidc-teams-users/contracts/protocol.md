# Contract: protocol additions (BackendCmdV1 / BackendEventV1)

Defined in Rust under `src/protocol/v1/`; TS generated by ts-rs. Additive to v1 (new variants only), so no version bump. Every variant needs a round-trip test. No variant carries a token, refresh token, client secret or admin API key in any response or event.

## Commands

| Command | Payload | Effect |
|---|---|---|
| `OidcSaveIssuer` | `OidcIssuerConfig` | Persist issuer config (non-secret). |
| `OidcSignIn` | `{ issuer_id, method: Browser \| DeviceCode }` | Start flow; emits `OidcSignInProgress`. |
| `OidcCancelSignIn` | `{ issuer_id }` | Abort in-flight flow. |
| `OidcSignOut` | `{ issuer_id, end_session: bool }` | Delete tokens, optional RP logout URL. |
| `SetContextAuthMode` | `{ context, mode, issuer_id? }` | Persist per-context auth mode; reconnect. |
| `IdpSetAdminKey` | `{ issuer_id, api_key }` | Store key in keyring (write-only; never echoed). |
| `IdpRefreshDirectory` | `{ issuer_id }` | Read users/groups (read-only). |
| `ResolveCapabilities` | `{ context, namespace? }` | Populate capability cache for a namespace. |
| `CheckCapability` | `CapabilityQuery` | Single verb/resource check (cluster-scoped or fallback). |
| `LinkTeamProfile` / `UnlinkTeamProfile` | `{ group, profile_id }` | Write `TeamLink` to the team store (014 publish path, secret scan applies). |
| `PreviewRoleAssignment` | `RoleAssignmentDraft` | Returns rendered YAML for the existing diff view. The apply is the existing `ApplyResourceYaml`. |

## Behavioural contracts

- Stale events (superseded request id, previous context) are discarded (Principle V).
- `ResolveCapabilities` failure yields `CapabilitiesResolved` with `incomplete=true` and empty rules, never allowed-by-default.
- `OidcSignIn` on an issuer whose discovery fails yields `OidcError{stage:"discovery"}`, no state change.
- MCP tools call the same resolver; a denial names identity, verb, resource, namespace (015 FR-005 preserved).

## External contracts consumed

- Rauthy OIDC: discovery, `/authorize`, `/token`, `/device`, `/certs`, `/logout`.
- Rauthy admin API (bearer API key): users list, groups list (read-only).
- Kubernetes: `SelfSubjectRulesReview`, `SelfSubjectAccessReview`, API server OIDC authentication.
