# Keyboard shortcuts

Press `?` anywhere in Fathom to see this list. Shortcuts don't fire while you are typing in a field.

## Global

| Keys | Action |
|---|---|
| `Ctrl+K` / `Cmd+K` | Open the command palette |
| `/` | Focus the filter of the active list |
| `?` | Show the shortcut list |
| `g` then `p` | Go to Pods |
| `g` then `d` | Go to Deployments |
| `g` then `n` | Go to Nodes |
| `Esc` | Close the inspector, dialog or overlay |

## In a list

| Keys | Action |
|---|---|
| `↓` / `↑` | Move the row cursor |
| `Home` / `End` | First / last row |
| `Enter` | Open the focused row in the inspector |
| `Space` | Select or deselect the row |
| `Delete` | Delete the focused or selected rows (asks first) |
